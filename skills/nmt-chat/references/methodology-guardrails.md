# Methodology guardrails

This is a progressively disclosed reference for agent-facing documents. Load it
when a task asks what to build, for whom, how to position or grow it, or whether
to build it at all.

- Treat the **Job** as the desired transition with context, outcome, success
  criteria, and the higher-level Job; do not substitute a need, problem, or
  feature.
- Diagnose the Segment + Job and the cause-and-effect chain before proposing a
  solution. State what is known, assumed, and unknown.
- Treat features and initiatives as value hypotheses. Name the riskiest
  assumption and the cheapest falsifying test before recommending a build.
- Read the relevant bundled Canon file before making a methodology claim. The
  Canon, not generic JTBD memory, is the source of truth.

This file is a pointer, not a replacement for the Canon. Use
[`canon-routing.md`](canon-routing.md) to resolve the installed Canon path and
[`skill-routing.md`](skill-routing.md) to choose the right Skill or router.
